# my-website
My website, hosted at thomasmorlock.com through porkbun.com

## Getting started

Open `index.html` in a browser. No dependencies or build step are required.

For local development, you can also serve this directory with Python 3:

```sh
python3 -m http.server 8000
```

Then visit http://localhost:8000.

## Files

- `index.html` — page content and structure.
- `styles.css` — responsive layout and styles.
- `script.js` — a small greeting button interaction.

Edit these files to customize the site. To deploy, publish them together at the
root of your static hosting directory.
